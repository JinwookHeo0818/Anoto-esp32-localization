CODE SEQUENCES AND CODEC ALGORITHM

The numerical MNS, A1, A2, A3, A4_alt sequences and the codec design are derived
from cheind/py-microdots by Christoph Heindl. This implementation uses the
anoto_6x6_a4_fixed variant. Inverse maps and periodic prefix sums are generated
from those sequences; they do not enumerate a physical floor or printed sheet.

https://github.com/cheind/py-microdots
https://raw.githubusercontent.com/cheind/py-microdots/develop/microdots/anoto_sequences.py
https://raw.githubusercontent.com/cheind/py-microdots/develop/microdots/codec.py
https://raw.githubusercontent.com/cheind/py-microdots/develop/microdots/integer.py

The upstream author expressly notes that A4_alt changes compatibility with
existing Anoto technology. This project is NOT a universal commercial Anoto
reader. It is compatible with the supplied Python pattern configuration.

OTHER COMPONENTS

Windows uses the operating system's Windows Imaging Component, not a bundled
third-party image decoding library. Linux uses system libjpeg and libpng.
Those libraries are not distributed in this ZIP. The vision pipeline and
standalone PC wrapper are new C++ implementations based on the supplied
Python processing structure. No OpenCV, Python, NumPy, or SciPy library is
embedded or required by the Windows executable.
